# D1000. 自维护分支的加载与手机布局

- **状态**：已实施
- **分组**：运行时
- **关联**：D12、D19、D39、D40、D42、D53

## 决定

- `maintained` 从 0.13.2 的源码提交继续开发，上游发行标签仍指向上游产物。生成文件只用于版本化发布目录，不进入源码分支。发布由维护者手动完成，fork 不执行上游 npm 发布。
- 对话流内的变动只刷新读取对话的功能；页面切换、设置、未知元素和服务变动仍请求完整刷新。侧栏年龄过滤只订阅目录元数据和侧栏结构，保护当前、固定、运行中及待处理会话，并提供全部显示。
- 延后功能保留原分块机制。封号页面点击后请求，对话导航与上下文等到对话出现后请求。首页可见且目录就绪后才计算统计，离开与切到后台停止轮询。
- 宿主库使用共享表的延迟 getter 获取，分块首次读取时才调用宿主加载器；源码与生成模块仍共享同一实例。手机复用宿主的 ReactDOM，避免重复打包与桌面上的额外求值。
- 日志目录用异步文件接口扫描，最多八个目录并行。搜索只在首次输入正文查询后创建索引，面板同次打开复用目录，批量缓存处理定期让出事件循环。
- 扩展 D12 的历史数据隔离：宿主读取旧记录时可以抛出无法解析旧描述符的错误。统计与搜索逐条报告这种读取失败，保留已有缓存并继续其余记录；统计通过 `failed` 和 `incomplete` 显示不完整状态。保存的会话文件从不改写。
- 扩展 D38 的资产缓存：内容哈希资产在一次路由注册期间缓存；开发构建仍每次读取清单，以支持重新构建。用户字体与账号数据不缓存。
- 手机功能在窄屏或触屏时才请求自己的分块，鼠标桌面不加载文本框模块；窄屏布局在宽屏卸下自己的标记与控件。原生文本框注册到官方输入插槽，使用输入状态与动作接口，同步在提交点完成以保持输入法稳定。工具折叠通过自己的按钮展开，原始控件仍由宿主处理。统计在独立区域，键盘高度使用可视视口事件更新。正式启用时关闭两个旧手机插件。
- 手机展开使用单一浮窗，会话操作与输入工具互斥，点击遮罩、关闭按钮或 Escape 收起。沿用 D52 的原位标记与固定定位，宿主控件不更换父元素；每簇按可视视口分配高度，超长内容在簇内滚动，顶栏与输入栏高度保持稳定。宽屏卸载和输入卡片更换时收起浮窗。
- 发布目录按版本不可变，profile 的设置条目固定为 `ui-skin-claude-maintained`。升级只切换该条目的模块路径，不随版本更换设置命名空间。
- 手机阅读只保留一行顶栏与一条输入栏。附件、工具与发送位于输入框左右，模型、权限、统计及可选目标控件在工具浮窗内保留原有操作；对话页不显示装饰吉祥物。用浏览器可视区域验收占用比例，浏览器自身栏位已经由该区域扣除。
- 懒渲染排除带 hidden 的行及其全部后代，保留宿主 hidden="until-found" 的折叠和查找展开语义。已完成轮次的中间输出、思考和工具记录随宿主一起收起，最终答案继续可见。
- 工作室首页的问候语与统计卡片水平居中。对话内的图片预览及 dsh-genui 的 Mermaid、SVG、图解居中；完整生成式卡片限制最大宽度并居中。正文、代码、卡片内部的组件排列及用户选择的聊天宽度沿用原有约定。

## 理由

维护分支需要可重现源码及明确宿主契约。流式文字不改变侧栏目录，隐藏页面不需要统计轮询。手机屏幕需要为输入和阅读保留空间，并兼容现有输入法插件。

## 代价

分页及布局仍依赖宿主服务和 DOM 标记。每个 DSH 新版本必须通过真实实例验证后再手动启用；fork 本身不保证未来兼容。

## 重审条件

宿主提供分页配置、原生手机布局或独立索引服务时，改用官方接口并移除相应覆盖。
